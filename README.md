# StudyLink Runtime Status — United Robotics World plugin

A read-only, right-side Capital panel for one StudyLink application runtime. Capital's native left chat is unchanged. The panel polls the CLI-owned `studylink.runtime-status.v1` sink every 1.5 seconds and displays only its sanitized allowlisted projection.

## Architecture and boundary

World injects `WORLD_PLUGIN_STATE_DIR`; the standalone RPC reads one fixed file:

```text
<WORLD_PLUGIN_STATE_DIR>/runtime-status.json
```

Configure the StudyLink CLI's `--runtime-status` option to that exact absolute file on the trusted host. The browser cannot provide or select a path. The RPC rejects symlinks, non-files, files over 128 KiB, unknown/additional fields, oversized collections and values outside the exact schema taxonomy. It reconstructs a bounded response and omits the source `runId`. Missing files are `idle`; non-terminal heartbeats older than the sink's `staleAfterMs` are `stale`.

The RPC does **not** read checkpoints/evidence, execute the CLI, duplicate form/Save/readback logic, or expose credentials, answers, raw IDs, digests, filenames or paths. It has no business-write method. Declarations, signatures, attachments, Next, Preview, Submit and finalize are explicitly manual/protected or unsupported, never controls.

The optional mount prop `{ "syntheticDemo": true }` selects a deterministic, visibly labelled synthetic fixture generated by the backend. It never reads or represents customer data and has four bounded polling steps.

Contract source: StudyLink CLI commit `90e4fa6e2fb55c59567c08f84fae2be4b8f16627`, `docs/RUNTIME_STATUS.md` and `src/runtime-status.ts`.

## Artifact contract

`npm run build` creates exactly:

```text
dist/manifest.json
dist/plugin.js
dist/rpc.mjs
```

`plugin.js` bundles React, ReactDOM and CSS with no runtime web dependency. `rpc.mjs` is dependency-free Node ESM. World invokes it with one version-1 JSON request on stdin and reads one response on stdout.

Methods:

- `studylink.status.read` — no parameters; reads the controlled sink.
- `studylink.demo.read` — `{ "tick": 0..3 }`; deterministic synthetic demo only.

## Develop and verify

Requires Node.js 22+.

```bash
npm ci
npm run check
```

`check` runs syntax/type checks, lint, a reproducible build, backend/privacy/artifact/browser behavior tests. CI also requires committed `dist/` to remain reproducible.

## Immutable installation

Pin all three artifacts to the exact full commit SHA through the manifest URL—never `main`, `latest`, or a movable tag:

```text
https://cdn.jsdelivr.net/gh/exisz/united-robotics-plugin-studylink@<FULL_40_CHARACTER_GIT_SHA>/dist/manifest.json
```

World derives `plugin.js` and `rpc.mjs` from the same immutable directory.

## Verification and identity scope

The panel renders only bounded facts from the CLI contract. Profile preflight is
`verified` with its preflight timestamp/source. Authentication is explicitly
`unknown`/`unavailable` because the current runtime does not return a reusable
auth-verification fact. Application, provider, and course identity are
`withheld`; raw names and IDs are never accepted. The exact finite form rail and
the optional tiny safe target label are the only displayed identity facts.
